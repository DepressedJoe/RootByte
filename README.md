# RootByte
A simple folder tool to remove redundant folder(s) inside a folder or "bite" a folder and spit out the "seeds" which in this case is the inner folder with the contents inside intact. 
Turns: (SumFile/sumfile/....) --into-> (sumfile/....) in seconds or more idk.

!! The root folder that you selected would be deleted and would only work on folders with folders inside !!
To run this, go to your preferred terminal and use the command "cd" to go to the folder that has the program "RootByte.java" then using the same Terminal type "java RootByte.java" (Java 11 needed or try other version, who knows it "might" work) for the app to open. Then boom, choose the folder you want to "bite"and wait.
